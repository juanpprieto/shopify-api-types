Add support for Shopify API 2025-10

- Added new types for Q4 2025 API release
- Updated scalar mappings for new GraphQL types
- Added support for new Admin API mutations
- Deprecated 2024-07 API version (now oldest supported)
- Breaking: Removed support for 2024-04 and earlier versions

This release updates the package to support the latest Shopify API version
(2025-10) and maintains the rolling 4-version support window.
